# Сервис To-do

Учебный список дел на JavaScript. Можно добавлять, копировать, удалять и редактировать задачи. Изменения сохраняются в localStorage и остаются после перезагрузки страницы.

Для запуска откройте `index.html` в браузере. Нажмите на карандаш, чтобы изменить задачу, и кликните вне текста для сохранения.

Проект выполнен на основе заготовки Яндекс Практикума `yandex-praktikum/to-do-pre`.
